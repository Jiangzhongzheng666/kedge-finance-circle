KEDGE Finance Circle landing page

1. Create a NEW public GitHub repository, for example: kedge-finance-circle.
2. Upload index.html and style.css from this folder. Do not upload this folder itself.
3. In Typeform, create your own form and copy its embed code or form ID.
4. In index.html, replace YOUR_FORM_ID with the Typeform form ID.
5. GitHub repository: Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Submit the GitHub Pages URL after it is live.

Do not use your existing my-profile repository for this assignment.
